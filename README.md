# talkative

React + Vite + TypeScript chat client.

```bash
npm install
npm run dev
```

Runs on [http://localhost:5173](http://localhost:5173). The API should be on port 4000 (`npm run dev` in `chat-app-week-17`).

For production builds set `VITE_API_URL` and `VITE_WS_URL` before `npm run build`.
